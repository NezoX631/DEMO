# ShoeShop - система оформления заказов обуви

Учебный проект: десктопное приложение для просмотра каталога обуви и оформления заказов.
Разработано для демонстрационного экзамена по специальности 09.02.07 «Информационные системы и программирование».
Компания-заказчик: торговая компания «Чудо Обувь».

## Возможности
- просмотр каталога моделей обуви с ценой, скидкой и наличием;
- сортировка, фильтрация и поиск товаров в реальном времени;
- подсветка товаров с критическим остатком (не более 3 пар);
- оформление заказа авторизованным пользователем;
- управление заказами и товарами (роли Менеджер и Администратор).

## Требования
- Python 3.10+
- PostgreSQL 14+
- Библиотеки из файла requirements.txt

## Установка и запуск
1. Клонировать репозиторий:
   `ash
   git clone https://github.com/NezoX631/DEMO.git
   cd DEMO
   `
2. Создать виртуальное окружение и установить зависимости:
   `ash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   `
3. Создать базу данных PostgreSQL и развернуть скрипт:
   `ash
   psql -U postgres -d shoe_shop -f database/shoe_shop.sql
   `
4. Скопировать config.ini.example в config.ini и указать свои параметры подключения:
   `ini
   [database]
   host = localhost
   port = 5432
   name = shoe_shop
   user = postgres
   password = your_password
   `
5. Запустить приложение:
   `ash
   python main.py
   `

## Схема базы данных (ER-диаграмма)
Концептуальная и логическая схема базы данных представлена в документе docs/er_diagram.pdf.
Основные таблицы системы:
- items - каталог моделей обуви, цены, скидки, категории и остатки на складе;
- users - учетные записи пользователей (администратор, менеджер, клиент);
- orders - оформленные заказы клиентов со статусами и датами доставки;
- pickup_points - пункты выдачи заказов;
- order_items - товарный состав каждого заказа.
